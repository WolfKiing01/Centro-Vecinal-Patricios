# Propuesta para Novedades y participación

Referencia: https://cvameghinosur.com.ar/ — diferencia novedades, gestiones y participación.

Proponemos reemplazar las tarjetas repetidas de talleres por:
1. Gestiones del barrio: fecha, problema, acción realizada y estado (presentado/en seguimiento/resuelto). Solo publicar avances confirmados por la comisión.
2. Avisos comunitarios: campañas, servicios, eventos y convocatorias con fecha y vencimiento.
3. Tu propuesta: enlace de WhatsApp para acercar una idea, avisar sobre un problema o enviar material para la cartelera. El centro revisa antes de publicar.

Primera etapa: WhatsApp existente y actualización manual del HTML. No necesita una base de datos propia ni correo institucional. El vecino debe enviar el mensaje en WhatsApp; no se publica automáticamente.

Segunda etapa opcional: formulario conectado a un servicio de formularios y revisión humana. La información se guarda en ese servicio.

Un muro de publicaciones automáticas sí necesita almacenamiento compartido y un backend o servicio externo, además de moderación y medidas contra abuso. El navegador por sí solo no comparte publicaciones con todos los vecinos.

Esta propuesta no agrega noticias inventadas ni abre un muro público. La sección actual queda lista para reemplazarse cuando se elija el formato y llegue la primera noticia real.
